HagridBot Privacy Policy

Last updated: August 1, 2026

This policy explains how HagridBot (Discord application ID 1072981047890939985) handles data when used in a Discord server.

Data HagridBot processes

HagridBot receives Discord message content, message metadata, user IDs, server IDs, channel IDs, role IDs, and attachment data only as needed to provide its features: text-trigger responses, spam detection, XP and ranks, configuration help, image generation, and chat responses.

Data HagridBot stores

HagridBot stores user and server IDs, XP totals and activity timestamps, rank and channel configuration, permission levels, and aggregated feature-use counts. It does not store ordinary message text or attachment contents in its database. Generated images may be temporarily stored on the bot host in order to send them to Discord.

Third-party processing

When a user invokes HagridBot's chat or configuration-help features, the relevant prompt and recent channel context may be sent to the bot's configured language-model provider. When a user invokes image generation, the image prompt is sent to Replicate. These providers process data under their own terms and privacy policies.

How data is used

Data is used only to operate, secure, maintain, and improve HagridBot's stated features. HagridBot does not sell personal data or use it for advertising.

Retention and deletion

Stored data is retained while it is needed to operate the bot, unless deleted sooner by the operator. A server administrator or affected user may request deletion of stored HagridBot data by contacting the operator at conczin@gmail.com. Requests should include the relevant Discord user ID and, if applicable, server ID.

Changes

This policy may be updated to reflect changes to HagridBot or applicable requirements. The current version will be published at this URL.
